# 基础功能完善范围

依据用户要求：分析并完善项目基础功能，暂不优化插件代码。

## 目标与边界

- 范围：内核配置、认证会话、公共错误/分页、文件与基础用户导入、前端请求/身份缓存、工程验收。
- 保持现有 Rust/Axum/sqlx 与 Vue/vue-query 架构，不新增第三方依赖，不修改插件、已发布迁移和 AGENTS.md。
- 基于现有数据库字段和权限点修复既有行为；不新增业务表、权限点或架构决策。
- 工作区其他并行变更独立保留；插件无法编译时先运行不依赖插件的内核回归。

## 验收条件

1. 非法环境变量使启动失败，合法容量变量可覆盖 TOML；缺省采样率与文档一致。
2. 并发单端登录只保留一个有效会话，插入失败保留旧会话；缓存失效后旧请求不能回填。
3. 退出失败不返回假成功；切换账号清除身份与数据缓存，旧请求不能恢复上一账号的数据。
4. 公共错误与登录限流遵守 problem+json，连接池不可用返回 503，分页不溢出。
5. 文件删除提交失败保留元数据和内容，正常删除及权限拒绝路径有真库验证。
6. 用户导入单行数据库异常不影响其他有效行，预校验不写用户；Excel 生成走受控阻塞池。
7. 运行内核单测、独立 PostgreSQL 回归、前端测试/构建、全仓库 verify 与接口生成；如被并行插件变更阻断，记录具体原因。

## 涉及数据与兼容性

- 使用既有 `sys_session`、`sys_file`、`sys_user` 及租户/策略表，无 DDL 变更。
- 复用既有 `system:user:add`、文件删除权限等权限常量，不增加权限。
- 成功响应字段保持兼容；退出存储失败及连接池不可用按现有错误模型返回 503。
- 回滚仅需回退本轮基础代码和文档，无迁移回滚；独立测试数据库由 sqlx 管理。
