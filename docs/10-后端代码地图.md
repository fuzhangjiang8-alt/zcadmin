# 10 · 后端代码地图

用途：快速找实现、联动修改和已知差距。以2026-11-10源码对照为基础；不再维护容易过期的全仓库行数/接口数/表数。规则见01～05，命令见07，验收见ci-local-rehearsal.md。

## 1. 入口与装配

| 路径 | 职责 |
|---|---|
| apps/server/src/main.rs | 配置、日志、插件链接、监听、优雅停机、契约导出入口 |

| crates/kernel/src/state.rs | AppState：连接池、配置、会话、存储、可信代理、停机标志 |
| crates/kernel/src/plugin.rs | Plugin契约、inventory收集、禁用过滤、校验与拓扑排序 |
| crates/xtask/src/main.rs、gen.rs | 工程命令及生成器实际能力 |

启动迁移或插件依赖失败应中止，不能带着部分未知结构对外就绪。后台任务重复执行与资源清理由相应实现负责。

## 3. 请求与数据边界

CurrentUser从Cookie/PAT解析身份；TenantTx设置事务级tenant/user。功能权限、租户RLS与部门/本人/custom范围分别校验。
平台身份才允许跨租户标记；scope收窄PAT不等同超管。ClientMeta是唯一IP来源，层顺序见01§3.1。
现有多处handler/read直接SQL是分层差距，不代表允许继续扩展该模式。

## 4. 基础关键行为

| 能力 | 必须联动考虑 |
|---|---|
| 单端会话 | tenant/user咨询锁+事务替换；失败保留旧会话 |
| 会话缓存 | 30秒、最多10000项、代次防回填；仅本实例失效 |
| 退出 | 撤销失败返回错误，成功才清Cookie/前端身份 |
| 文件删除 | 先提交软删再删物理内容；提交失败保留文件 |
| 用户导入 | 最多500行、逐行保存点、dryRun不新增用户、错误不导出口令 |
| Excel | 构造/解析使用受控阻塞池，不因tokio后台任务而省略限流 |
| 错误 | problem+json、连接池不可用503，错误码与契约一致 |
| 分页 | size1..200，OFFSET饱和防溢出 |

前端实现入口为frontend/src/api/client.ts、api/query-client.ts、stores/session.ts和composables/useDict.ts；身份切换清全部查询缓存并阻止旧请求恢复数据。

## 5. RLS查询入口与例外

静态脚本 `scripts/check-rls-coverage.mjs` 检查迁移里的策略/FORCE，真实部署另外验证。
查实际库时核对pg_class.relrowsecurity/relforcerowsecurity，覆盖启用插件schema；不固定抄写历史表数。
sys_session在token解析阶段没有tenant上下文，管理操作显式过滤tenant；sys_tenant/sys_permission为全局域。分区父表策略、直接子表权限和未来授权都须核查。
owner及普通角色测试位于apps/server/tests/rls_enforced.rs，不能用超级用户执行结果证明隔离。

## 8. 当前差距

- 分层/文件规模不完全达到规范，功能权限多由handler显式校验，不能把静态门禁视为完整安全审计。
- Outbox、持久任务调度、完整生命周期钩子、热装及资源沙箱未实现。
- Refresh/MFA/空闲超时、错误/慢请求全采样未实现。
- 会话失效/登录限流为进程内；文件全量读取，物理删除缺自动重试；部分导出仍持长事务。
- 前端分包/通用UI与测试平台未全面落地；生产角色、设备/浏览器、容量和部署仍按实际证据验收。
