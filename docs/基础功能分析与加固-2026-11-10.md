## 1. 范围

内核配置、认证会话、公共响应/分页、文件、基础用户导入、前端请求/身份缓存及工程门禁。
未新增表/依赖/权限，未改已发布迁移与AGENTS；插件业务不在该轮优化范围。工作区并行变化不计作本轮成果，目录无.git不能提供提交归属。

## 2. 完善内容

| 能力 | 结果与定位 |
|---|---|
| 配置 | config/env.rs显式解析部署变量；loading.rs校验超时/容量，统一缺省采样0.1 |
| 请求 | client.ts保留HeadersInit和HTTP错误状态，FormData不强设类型，异常成功体显式失败 |
| 前端身份/缓存 | session.ts代次防旧响应复活身份；共享QueryClient，字典接入可取消查询，切身份清缓存 |
| 单端登录 | session/create.rs事务锁串行替换，插入失败保留旧会话 |
| 会话缓存/退出 | 有界缓存防旧查询回填；撤销失败返回错误，成功才清Cookie与本地身份 |
| 错误/分页 | problem+json，连接池不可用503，登录429保留重试头，OFFSET饱和防溢出 |
| 文件 | 提交软删后删物理内容；提交失败保留文件；下载前释放只读事务 |
| 用户导入 | 逐行保存点隔离SQL异常，dryRun不写用户，错误写入详情只进日志 |
| 受控执行 | 模板/错误报告和初始化哈希使用受控阻塞入口，错误报告限500行且不含密码 |
| 门禁 | verify增加权限/错误码检查，基础真库测试位于kernel并接入CI |

## 部署配置

完整变量及安全要求只维护在[05 §7](05-安全合规与运维.md#7-部署配置)，默认值来自config/default.toml与源码。
本轮变化是Config的非法数字/布尔值不再静默忽略，以及补齐容量/会话/存储覆盖；部署前核对现有环境值。
初始化口令不覆盖已有账号；请求超时须分别大于非零的取连接/SQL超时，预热连接不能超过上限。

## 3. 验证与兼容

上一轮验收覆盖并发单端登录、失败回滚、文件提交失败/权限、用户导入部分成功和预校验、HTTP契约及前端缓存竞态。
具体时间、数量和当前失败项仅以[验收记录](ci-local-rehearsal.md)为准，文档精简不产生新的运行验收结论。
成功字段保持兼容，退出失败/连接池不可用遵守现有503语义。回退该轮实现与契约无需DDL回滚，但代码回退不恢复已删除文件。

## 4. 剩余风险

- 会话跨实例撤销最长30秒，登录限流按实例计数。
- 文件下载全量内存，物理删除缺自动重试；同步用户导入最多500行，部分导出仍持事务。
- handler SQL分层仍需逐步收敛；Outbox、持久调度、Refresh/MFA等未实现。
- 真库基础回归不证明生产角色RLS，前端构建不证明浏览器/设备，容量与部署需独立验收。
