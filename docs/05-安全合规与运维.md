# 05 · 安全合规与运维交付

本文集中维护部署、安全、环境变量和故障处理。实现定位见10，开发验证命令见07，实际验收见ci-local-rehearsal.md。目标与已实现必须分开。

## 1. 安全基线

### 1.1 身份与权限

当前为数据库用户、Argon2id、HttpOnly Cookie及可收窄PAT；默认会话8小时，失败5次锁15分钟，登录IP限流60次/分钟，租户策略可调整。
单端替换事务化，退出存储失败不能假成功。会话/限流均有进程内状态，多实例撤销最长30秒窗口，阈值按实例放大。
初始账号只作用于空库：release构建一律要求首登改密（`AUTH_FORCE_PASSWORD_CHANGE=true/false`可显式覆盖，用于「播种后立即调接口」的自动化）。
PAT是独立凭据：重置密码、停用账号、停用/删除租户会同时吊销令牌；令牌解析还要求租户为active。
MFA、双令牌轮换、空闲超时、二次认证票据是目标，未实现。PAT可创建为永不过期（调用方显式选择），产品上应评估默认有效期。

### 1.2 必守边界

- HTTPS与可信网关；Cookie安全属性、CORS与Host按部署核对，禁止随意放开来源。
- 应用数据库角色NOSUPERUSER/NOBYPASSRLS，tenant表同时有策略、ENABLE和FORCE。
- 功能权限、资源归属、租户隔离、数据范围分别验证；资源越权返回404，无功能权限403。
- IP只取ClientMeta；仅TCP对端属于可信代理时才解析转发链，不能信客户端伪造头。
- panic保持unwind；重CPU/内存走受控阻塞池；所有等待、重试和容量有上限。
- 口令/token/密钥/完整连接串与敏感原始体不进日志、仓库或错误响应。

## 2. 出站、上传与供应链

用户可控URL统一走ssrf校验，且分两档：保存时查字面量+真实DNS解析结果（防「公网域名解析到内网」），投递前再复检一次（防配置导入覆盖与域名改指内网）；被拒的投递直接进死信不重试。
当前Webhook仅http(s)，拒绝元数据/保留等地址；release限制私网/环回/CGNAT/文档段，debug为回环测试保留例外；投递禁用重定向并设超时。
解析与建连之间仍存在重绑定窗口（TOCTOU），生产还需出口域名/IP/端口限制及网络策略，不开放任意服务端抓取。
文件key服务端生成，限制大小/类型、校验归属；完整魔数/杀毒/隔离扫描不能在未实现时宣称覆盖。
锁文件入库；新增依赖先ADR批准，发版检查漏洞/许可证/SBOM与制品来源。cargo audit/deny等需实际执行，配置存在不等于检查通过。

## 3. 合规与留存

等保/OWASP是验收目标，必须逐项附实现、配置、扫描和测试证据，不能仅以架构说明声明达标。
审计默认180天，记录关键身份、授权、配置、导入导出、租户操作；敏感字段脱敏，审计本身也需访问权限。
哈希链、WORM、冷归档、静态/字段加密及备份加密按真实部署落实；尚未建成的部分列入差距，不把规划当证据。

## 4. 可观测性与告警

| 入口 | 当前用途 |
|---|---|
| /healthz | 进程存活，不检查依赖 |
| /readyz | 数据库可用与停机标志，失败应摘流 |
| /metrics | Prometheus；默认只允许本机/进程内读取，远程抓取必须设置METRICS_TOKEN（未设置时远程返回404） |
| 日志/Tracing | RequestId、INFO访问日志，可选OTLP；LOG_FORMAT=json便于采集 |
| 审计告警 | 规则/窗口/阈值、确认、订阅与Webhook投递 |

默认追踪采样0.1，错误/慢请求100%采样未实现。监控请求错误率/P95、连接等待、慢SQL、阻塞池、磁盘、锁/复制与任务失败。
SLO、容量、灰度、RPO/RTO目标见总览，必须经实际统计/演练验收。

## 5. 发布与回滚

1. 核对制品版本、插件features/禁用集合、配置、权限和契约；完成07中的对应门禁。
2. 备份并确认可恢复，再按Expand-Contract执行迁移；新版本先兼容旧数据/接口。
3. 小范围发布，检查readyz、日志、错误率、延迟与关键写入，再扩大流量。
4. 异常先停止扩量/摘流，按兼容性回退应用；不可逆DDL或数据破坏按恢复计划处理，不能只换二进制。

禁止手改已发布迁移、手改生成物或临时生产改数。数据库变更评审见03。回滚目标5分钟是既定目标，不是当前演练结论。

## 6. 备份与灾备

生产建立全量/增量+WAL、异地与加密、保留期和密钥分离。季度在隔离环境恢复，记录实际丢失窗口和恢复时间。
备份成功不等于可恢复；灰度、PG故障转移、SIGTERM排空及回滚都需独立演练。Redis/对象存储等未来依赖需给出故障降级方案，不能承诺现有未验证的自动切换。

## 7. 部署配置

### 7.1 交付与启动

默认值源为 `config/default.toml` 与config.rs；加载优先级：代码默认 < TOML < 环境变量。
文件缺失可用默认值+环境变量，文件不可读/损坏则失败。生产设置CONFIG_PATH、数据库/存储持久化、强初始密码与网络出口。
Docker路径/挂载以Dockerfile、docker-compose.yml为准；已有数据卷按 `ops/init-app-role.sql` 补角色，不删卷代替升级。
当前前端通过web_dist目录托管，不是rust-embed全内嵌；制品需包含匹配前端资源。

### 7.2 完整变量清单

| 范围 | Config解析的环境变量 |
|---|---|
| HTTP | BIND_ADDR、WEB_DIST、CORS_ORIGINS、TRUSTED_PROXIES、MAX_CONCURRENCY、REQUEST_TIMEOUT_SECS、SHUTDOWN_GRACE_SECS、EXPOSE_API_DOCS |
| 数据库 | DATABASE_URL、DB_MAX_CONNECTIONS、DB_MIN_CONNECTIONS、DB_ACQUIRE_TIMEOUT_SECS、DB_MAX_LIFETIME_SECS、STATEMENT_TIMEOUT_SECS |
| 身份 | AUTH_DEV_USERNAME、AUTH_DEV_PASSWORD、AUTH_FORCE_PASSWORD_CHANGE、AUTH_SESSION_TTL_SECS、AUTH_MAX_FAILED_ATTEMPTS、AUTH_LOCK_SECONDS、AUTH_SINGLE_SESSION |
| 文件/维护 | STORAGE_LOCAL_DIR、STORAGE_MAX_FILE_BYTES、AUDIT_RETENTION_DAYS、TENANT_RETENTION_DAYS、TENANT_BILL_OVERDUE_DAYS |
| 追踪 | OTEL_EXPORTER_OTLP_ENDPOINT、OTEL_TRACES_SAMPLER_ARG |
| 插件启用 | DISABLED_PLUGINS（启动过滤，非热切换） |

其他模块单独读取：CONFIG_PATH、LOG_FORMAT、METRICS_TOKEN、BLOCKING_MAX_CONCURRENCY、LOGIN_RATE_LIMIT_PER_MIN；不能从Config校验推断它们也经过同样解析。

| 部署重点 | 要求 |
|---|---|
| AUTH_DEV_PASSWORD | 生产初始化提供强口令，不重置已有账号；release构建首登强制改密 |
| DATABASE_URL | 生产应用使用非超级用户且无BYPASSRLS |
| TRUSTED_PROXIES | 网关后按真实来源网段设置，禁止信任所有地址 |
| EXPOSE_API_DOCS | 公网关闭，或另行限制/docs与/api/openapi.json |
| METRICS_TOKEN | 未设置时/metrics仅本机可达；远程抓取必须设置，并保留网络隔离 |
| AUTH_FORCE_PASSWORD_CHANGE | 仅自动化部署（播种后立刻调接口）才设false；其余情况保持默认强制改密 |
| DB_MAX_CONNECTIONS | 实例总连接池与后台/运维连接不得超PG预算 |

### 7.3 解析与预算

Config的非法数字/布尔值中止启动，错误仅报告变量名；布尔支持true/false、1/0、yes/no，列表逗号分隔去空项，空OTLP端点关闭远程追踪。
请求超时分别大于取连接和SQL超时，后二者非零；预热连接≤最大连接。MAX_CONCURRENCY=0按CPU推导，不代表无限容量。
默认请求30秒、取连接/SQL各5秒、池20/预热5、阻塞并发4；每个Argon2并发约19MiB，调大前核算内存。
排空默认20秒另加3秒摘流，编排宽限必须更大，compose默认40秒。

## 8. 运维操作

### 8.1 故障定位

| 现象 | 先查 | 处理边界 |
|---|---|---|
| 502/504 | 网关、RequestId日志、连接等待、慢SQL | 先定位，不靠无限重试 |
| 503 | 并发/阻塞池/连接池、readyz | 降载/摘流，Retry-After通用5秒 |
| 登录429 | 可信IP与实例计数 | 等待窗口，Retry-After60秒 |
| 退出失败 | 会话数据库撤销 | 保留身份提示重试，不假成功 |
| 迁移卡住 | pg_locks、pg_stat_activity、咨询锁 | 核对阻塞再按变更流程处理 |
| 文件删除失败 | 软删记录、storage_key、磁盘权限 | 提交失败保留文件；物理删除失败需人工/运维重试 |
| 投递失败 | 超时/网络/响应码、重试时间、死信 | 先修地址/网络，再有界重投 |

### 8.2 审计、告警与配置操作

具体URL/字段以OpenAPI和前端操作为准，不在此重复完整接口清单。

| 能力 | 操作约束 |
|---|---|
| 审计查询/导出 | 受权限/租户/时间范围约束，导出最多20000行，不记录秘密 |
| 规则与静默 | 核对动作模式、窗口/阈值、启用和静默时段，保留兜底规则要求 |
| 站内订阅/Webhook | 核对目标、模板与签名密钥；默认关闭/显式启用，失败有退避与死信 |
| 死信重投 | 先排故，再单条/批量重投；保留审计、次数和错误原因 |
| 配置包/快照 | 导入前预览差异、选择范围、版本兼容；回滚预览后再确认，记录操作者与结果 |
| PAT/在线会话 | scope最小化，撤销与踢人可审计，不展示原始令牌；保留多实例TTL说明 |
| 租户生命周期 | 停用/软删撤销会话；恢复保留数据；物理清理先dryRun并核对保留期/目标，不可逆 |
| 配额与账单 | 服务端配额兜底；账单草稿、出账、支付/退款、催收与对账遵循现有状态机，禁止运维直接改状态 |

### 8.3 每日与发版核查

检查备份/WAL、磁盘/分区、复制/锁、错误/P95、任务/死信及异常登录；权限撤销、跨租户、资源越权和导出访问发版必测。
自动孤儿文件清理、持久任务队列、备份自动恢复等未落地能力单独列风险，不能以日志/监控存在宣称已闭环。
